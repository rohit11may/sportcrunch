<task type="auto">
  <name>Task 2: Consolidate debug logging in AudioAnalyzer</name>
  <files>SportCrunch/Core/Services/AudioAnalyzer.swift</files>
  <action>
Replace the pattern of print() + logger.xxxAsync() with single logger calls:

1. Keep high-level progress at normal level:
   - "Starting audio analysis for {sport} ({mode})..."
   - "Step X/5: {description}..."
   - "Extracted {N} samples ({duration})"
   - "Found {N} peaks, {N} candidate intervals"

2. Move detailed stats to verbose level:
   - Preset configuration details (sample rate, bandpass, thresholds)
   - Onset strength statistics (min, max, mean, stdDev)
   - Peak detection details (first 20 peaks)
   - Cluster information

3. Move debug fingerprints to debug level:
   - Audio fingerprint values
   - First 10 samples, samples at 1s
   - Filtered audio fingerprint

Remove the print() calls entirely - all output goes through ProcessingLogger.

Keep the decorative separators (═══, ───) in verbose messages for readability.

Do NOT modify:
- Algorithm logic (onset detection, filtering, clustering)
- Debug data structure population (AudioAnalysisDebugData)
- Quantization operations (these are algorithmic, not debug logging)
  </action>
