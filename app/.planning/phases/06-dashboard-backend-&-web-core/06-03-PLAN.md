  <action>
    Create `Timeline.jsx` component:

    **Props:**
    - `segments` - Array of segment objects: `[{startTime, endTime, type}]`
    - `onSegmentClick(timestamp)` - Callback when segment is clicked
    - `currentTime` - Current video playback position (for position indicator)
    - `videoDuration` - Total video duration for timeline scale

    **State:**
    - `showRejected` - Boolean toggle for viewing original (all) vs final (kept only)

    **Implementation:**
    - Calculate timeline scale: map video duration to pixel width (e.g., 800px)
    - Render toggle button: "Show Rejected Segments" / "Hide Rejected Segments"
    - Filter segments based on `showRejected`:
      - When false: show only segments with `type === "kept"` (green)
      - When true: show all segments (green for kept, red/gray for rejected)
    - Render segments as horizontal bars:
      - Position: `left = (startTime / videoDuration) * width`
      - Width: `width = ((endTime - startTime) / videoDuration) * width`
      - Color: green (#4ade80) for kept, red/gray (#ef4444) for rejected
      - Height: 40px bars with 4px gap
      - Add hover effect (brightness increase)
      - onClick triggers `onSegmentClick(segment.startTime)`
    - Render time axis with tick marks (0s, 30s, 60s, etc.)
    - Render current position indicator (vertical line at currentTime)

    **Accessibility:**
    - Add ARIA labels for segments
    - Keyboard navigation (arrow keys to move between segments, Enter to select)

    Create `Timeline.css`:
    - Flexbox layout for timeline container
    - Absolute positioning for segment bars
    - Smooth transitions for hover states
    - Responsive width (100% of container)
  </action>
  <verify>
    - Timeline renders segments as colored bars
    - Toggle button switches between original/final views
    - Clicking segment logs timestamp to console (before VideoPlayer integration)
    - Timeline scales correctly for different video durations
    - Position indicator moves across timeline
  </verify>
