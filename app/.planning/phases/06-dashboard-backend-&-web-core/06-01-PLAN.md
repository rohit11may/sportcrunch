  <action>
    Add iOS Runner proxy endpoints to `backend/server.js`:

    **POST /api/runs** - Proxy to iOS Runner:
    - Accept JSON body: `{videoPath, method, sport, sportMode?, config?}`
    - Validate required fields (videoPath, method, sport)
    - Forward to `http://localhost:8080/runs` using fetch
    - Add configurable iOS Runner URL via RUNNER_URL env var (default: http://localhost:8080)
    - Return iOS Runner response (202 Accepted with run ID)
    - Handle connection errors (runner not running) with clear error message

    **GET /api/runs** - Proxy list runs:
    - Forward to `http://localhost:8080/runs`
    - Return runs array from iOS Runner

    **GET /api/runs/:id** - Proxy get run:
    - Forward to `http://localhost:8080/runs/:id`
    - Return run details from iOS Runner
    - Handle 404 if run not found

    Add health check endpoint:
    **GET /api/health** - Backend health:
    - Check iOS Runner health at `http://localhost:8080/health`
    - Return `{backend: "ready", runner: "ready" | "unavailable"}`
    - Don't fail if runner unavailable, just report status

    Add error handling for iOS Runner connectivity issues (ECONNREFUSED, timeout).
