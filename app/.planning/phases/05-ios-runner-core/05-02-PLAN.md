    Create RunStore.swift:
    - actor RunStore (thread-safe)
    - Private dictionary [UUID: Run]
    - Methods: add(run), update(run), get(id), getAll(), delete(id)

<task type="auto">
  <name>Task 2: Create ArtifactExporter and RunExecutor</name>
  <files>SportCrunchRunner/Services/ArtifactExporter.swift, SportCrunchRunner/Services/RunExecutor.swift</files>
  <action>
    Create ArtifactExporter.swift:
    - Class ArtifactExporter
    - Shared filesystem base path: ~/Library/Developer/CoreSimulator/Devices/.../data/Documents/SportCrunchRunner/Runs/
      (Use FileManager.default.urls(for: .documentDirectory, in: .userDomainMask) - simulator maps this to Mac)
    - Method: export(run: Run, segments: [ActionSegment], highlightURL: URL?) async throws -> ArtifactPaths
    - Creates run directory: {base}/{runId}/
    - Writes segments.json with format: {"segments": [{"startTime": N, "endTime": N, "type": "..."}], "metadata": {...}}
    - Copies highlight video to {base}/{runId}/highlight.mp4 (if exists)
    - File naming per CONTEXT: 20260121-143022-SpectralFlux-segments.json
    - Returns ArtifactPaths with absolute paths

    Create RunExecutor.swift:
    - actor RunExecutor
    - Dependencies: RunStore, ArtifactExporter
    - Private queue: [UUID] (run IDs waiting)
    - Private currentRun: UUID? (run in progress)
    - Method: enqueue(run: Run) - adds to store and queue, triggers processNext()
    - Private method: processNext() - if currentRun nil and queue not empty, pop and execute
    - Private method: executeRun(run: Run) async
      - Update status to running, startedAt
      - Load video from run.videoPath
      - Create SpectralFluxMethod (or look up by run.method name - for now just SpectralFlux)
      - Call method.detectSegments(videoURL:sport:sportMode:)
      - On success: export artifacts, update run with segments and artifactPaths, status completed
      - On failure: update run with error message, status failed
      - In all cases: set completedAt, call processNext()

    Note: For simulator, video path should be accessible. Dashboard will provide path from shared filesystem.
  </action>
  <verify>Files compile, no Swift errors</verify>
  <done>RunExecutor processes runs through SpectralFluxMethod and exports artifacts via ArtifactExporter</done>
</task>
