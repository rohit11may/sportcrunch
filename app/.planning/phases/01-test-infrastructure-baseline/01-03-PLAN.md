Create Smoke.xctestplan at project root (SportCrunch.xcodeproj/ directory).

Test Plans are JSON files with this structure:

```json
{
  "configurations": [
    {
      "id": "SMOKE_CONFIG",
      "name": "Smoke Tests",
      "options": {
        "testTimeoutsEnabled": true,
        "maximumTestExecutionTimeAllowance": 300,
        "defaultTestExecutionTimeAllowance": 60
      }
    }
  ],
  "defaultOptions": {
    "testTimeoutsEnabled": true
  },
  "testTargets": [
    {
      "target": {
        "containerPath": "container:SportCrunch.xcodeproj",
        "identifier": "SPORTCRUNCH_TESTS_TARGET_ID",
        "name": "SportCrunchTests"
      },
      "selectedTests": [
        "SegmentDetectionTests/testRallyDetection_Tennis()"
      ]
    }
  ],
  "version": 1
}
```

**Configuration details:**
- `maximumTestExecutionTimeAllowance`: 300 seconds (5 minutes total for smoke suite)
- `defaultTestExecutionTimeAllowance`: 60 seconds per test (overridden by test-specific settings)
- `selectedTests`: Explicitly list smoke tests - currently just the rally detection test
- As more tests are added in Phase 2/3, smoke suite will grow selectively

**Purpose:**
Smoke tests run during development for quick feedback. They validate core functionality without exhaustive coverage. Developers should be able to run smoke tests in <2 minutes to catch regressions quickly.

To find the target identifier, check the project.pbxproj file or use a placeholder that Xcode will resolve. Alternatively, use the simpler format without explicit identifier:

```json
{
  "configurations": [
    {
      "id": "SMOKE_CONFIG",
      "name": "Smoke Tests",
      "options": {
        "testTimeoutsEnabled": true,
        "maximumTestExecutionTimeAllowance": 300,
        "defaultTestExecutionTimeAllowance": 60
      }
    }
  ],
  "defaultOptions": {
    "testTimeoutsEnabled": true
  },
  "testTargets": [
    {
      "target": {
        "containerPath": "container:SportCrunch.xcodeproj",
        "name": "SportCrunchTests"
      },
      "selectedTests": [
        "SegmentDetectionTests/testRallyDetection_Tennis()"
      ]
    }
  ],
  "version": 1
}
```

Use the simpler format (without identifier) - Xcode will resolve the target automatically.

  <name>Task 2: Create Regression.xctestplan for comprehensive pre-commit suite</name>

  <action>
Create Regression.xctestplan at project root (SportCrunch.xcodeproj/ directory).

```json
{
  "configurations": [
    {
      "id": "REGRESSION_CONFIG",
      "name": "Regression Tests",
      "options": {
        "testTimeoutsEnabled": true,
        "maximumTestExecutionTimeAllowance": 1800,
        "defaultTestExecutionTimeAllowance": 120
      }
    }
  ],
  "defaultOptions": {
    "testTimeoutsEnabled": true,
    "codeCoverage": {
      "targets": [
        {
          "containerPath": "container:SportCrunch.xcodeproj",
          "name": "SportCrunch"
        }
      ]
    }
  },
  "testTargets": [
    {
      "target": {
        "containerPath": "container:SportCrunch.xcodeproj",
        "name": "SportCrunchTests"
      }
    }
  ],
  "version": 1
}
```

**Configuration details:**
- `maximumTestExecutionTimeAllowance`: 1800 seconds (30 minutes total - generous for future test growth)
- `defaultTestExecutionTimeAllowance`: 120 seconds per test
- `testTargets`: No `selectedTests` - runs ALL tests in SportCrunchTests target
- `codeCoverage`: Enable coverage tracking for main app target

**Purpose:**
Regression tests run before commits to validate entire system. Currently contains same tests as smoke, but as test suite grows in Phase 2/3:
- Smoke: ~5-10 quick tests for rapid feedback
- Regression: All tests (could be 50+ tests validating edge cases, error paths, etc.)

**Difference from Smoke:**
- Regression runs ALL tests (no selectedTests filter)
- Longer timeout allowances
- Code coverage enabled
- Intended for pre-commit, not during active development
