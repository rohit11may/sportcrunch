Create a new file `SegmentationMethod.swift` that defines the protocol for detection methods.

The protocol should:
1. Be an async protocol (methods return async)
2. Define a single method: `detectSegments(videoURL: URL, sport: Sport, sportMode: SportMode?) async throws -> [ActionSegment]`
3. Include a `name` property for identifying the method (String)
4. Include optional protocol extensions for common functionality if useful

Key considerations:
- The protocol should NOT expose intermediate data yet (that's Phase 5: METH-04)
- Keep it minimal - just what's needed for Phase 4 requirements
- Use `any SegmentationMethod` for type erasure where needed
- Consider using `Sendable` constraint since methods may run on background threads

Example signature:
```swift
protocol SegmentationMethod: Sendable {
    var name: String { get }
    func detectSegments(videoURL: URL, sport: Sport, sportMode: SportMode?) async throws -> [ActionSegment]
}
```
