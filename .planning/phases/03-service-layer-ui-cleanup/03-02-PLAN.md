  <action>
Create a new ThumbnailService for video thumbnail generation:

1. Create protocol `ThumbnailServiceProtocol`:
   ```swift
   protocol ThumbnailServiceProtocol {
       func generateThumbnail(from videoURL: URL, maxSize: CGSize?) async -> Data?
   }
   ```

2. Create `RealThumbnailService` implementation:
   - Move the generateThumbnail logic from BackgroundProcessingManager
   - Use default maxSize of CGSize(width: 400, height: 400) if nil passed
   - Use compression quality 0.7 (JPEG)
   - Keep the existing behavior: extract middle frame

3. Create `MockThumbnailService` for testing:
   - Returns nil (for tests that don't need thumbnails)
   - Or returns a small placeholder image data

Follow existing conventions:
- Protocol in same file as implementation
- Use `// MARK:` to organize sections
- Actor or class based on thread safety needs (class is fine since AVAssetImageGenerator handles its own threading)
