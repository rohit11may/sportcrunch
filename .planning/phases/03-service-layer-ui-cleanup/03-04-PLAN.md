           logger: ProcessingLogger?

   - Contains all 4 loading strategies from HighlightCreationViewModel

   - Keep the same fallback chain logic
   - Move VideoTransferable struct to this file

3. Error handling:
   - Create `VideoLoaderError` enum with cases: noAssetIdentifier, fetchFailed, loadFailed, cancelled
   - Use existing error messages for logging

4. Create `MockVideoLoaderService` for testing:
   - Returns a configured mock URL or throws on demand

Follow existing conventions:
- Protocol in same file
- `// MARK:` sections for organization
