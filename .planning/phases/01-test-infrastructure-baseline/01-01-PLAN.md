Create SegmentEvaluator struct in SportCrunchTests/Helpers/ directory (create Helpers/ if needed).

Implement three core functions following the research patterns:

1. `iou(detected:groundTruth:) -> Double` - Calculate Intersection over Union for temporal ranges
   - Input: Two TimeRange structs (start, end)
   - Output: IoU value 0.0-1.0
   - Formula: intersection / union for temporal intervals
   - Handle edge case: union = 0 returns 0.0

2. `evaluate(detected:groundTruth:iouThreshold:) -> (tp: Int, fp: Int, fn: Int)` - Match segments using IoU
   - Default iouThreshold: 0.5
   - Greedy matching: each detected segment matches best ground truth segment above threshold
   - Track matched ground truth indices to avoid double-matching
   - Return tuple: (true positives, false positives, false negatives)

3. `calculateRates(detected:groundTruth:) -> (fpRate: Double, fnRate: Double)` - Calculate FP/FN percentages
   - FP rate: extra duration kept / ground truth total duration * 100
   - FN rate: missed duration / ground truth total duration * 100
   - Handle edge case: zero ground truth duration returns 0.0 for both rates

Use existing Segment model from codebase (has start, end, duration properties). If TimeRange helper is needed, define it inline in this file.

**2. Ground Truth JSON Format:**
Provide complete schema with example:
```json
{
  "videoFilename": "rally-tennis-01.mp4",
  "sport": "tennis",
  "mode": "rally",
  "segments": [
    {
      "start": 2.5,
      "end": 6.8
    },
    {
      "start": 8.1,
      "end": 11.3
    }
  ]
}
```

Explain:
- `sport`: Sport type (e.g., "tennis", "cricket")
- `mode`: Detection mode (e.g., "rally", "shot") - applies to all segments in this file
- `segments`: Array of time intervals representing ground truth
- `start`/`end`: Timestamps in seconds (Double precision)
- File naming: JSON filename must match video filename (e.g., `rally-tennis-01.mp4` → `rally-tennis-01.json`)

**3. Video Requirements:**
- Format: MP4 (H.264 video, AAC audio preferred)
- Duration: 10-30 seconds for quick test execution
- Content: Should contain clear examples of what needs detecting (rallies, shots)
- Naming: Descriptive pattern: `{mode}-{sport}-{number}.mp4` (e.g., `rally-tennis-01.mp4`, `shot-tennis-01.mp4`)
