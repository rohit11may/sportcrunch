  <action>
Create test harness that runs all methods on all videos and collects metrics.

**Create these dataclasses:**

1. **MethodVideoResult**:
   - `method_name: str`
   - `video_filename: str`
   - `ground_truth: GroundTruth`
   - `method_result: MethodResult` (from framework)
   - `metrics: EvaluationMetrics`
   - `processing_time: float` (seconds)
   - `error: Optional[str]` (if method crashed)

2. **HarnessResult**:
   - `results: List[MethodVideoResult]`
   - `timestamp: str` (ISO format)
   - `total_methods: int`
   - `total_videos: int`
   - Method `to_table() -> str`: renders results as formatted table
   - Method `to_summary() -> Dict`: aggregates metrics per method (avg precision, recall, F1, time)

**Create TestHarness class:**

1. **Constructor**:
   - `__init__(iou_threshold: float = 0.5)`: stores IoU threshold for evaluation

2. **Core execution method**:
   - `run_all(verbose: bool = True) -> HarnessResult`:
     * Discover methods: `methods = get_registered_methods()` (from framework registry)
     * Load ground truth: `gt_loader = GroundTruthLoader(); all_gt = gt_loader.load_all()`
     * For each method class in methods:
       * Instantiate: `method = MethodClass()`
       * For each ground truth in all_gt:
         * Resolve video path: `video_path = VideoLoader().resolve_path(gt.video_filename)`
         * Get video metadata for duration: `metadata = VideoLoader().get_metadata(video_path)`
         * Time execution: `start = time.time()`
         * Run method: `method_result = method.analyze(video_path)` (wrapped in try/except)
         * Calculate elapsed: `processing_time = time.time() - start`
         * If success: evaluate using `SegmentEvaluator.evaluate(method_result.segments, gt.as_time_ranges(), iou_threshold)`
         * If failure: store error message in MethodVideoResult
         * If verbose: print progress (e.g., "✓ StubMethod on tennis-shot-1.mp4: P=0.85 R=0.90 F1=0.87 (0.12s)")
     * Create HarnessResult with all MethodVideoResults
     * Return result

3. **Helper methods**:
   - `_format_progress(method_name: str, video: str, metrics: EvaluationMetrics, time: float) -> str`:
     * Returns formatted string for verbose output
   - `_safe_analyze(method, video_path) -> Tuple[Optional[MethodResult], Optional[str]]`:
     * Wraps method.analyze() in try/except
     * Returns (result, None) on success or (None, error_message) on failure

**HarnessResult.to_table() implementation:**
- Use simple text table format with columns: Method | Video | Precision | Recall | F1 | Time
- Sort by method name, then video name
- Include summary row per method (averages)
- Width: ~100 chars, aligned columns

**HarnessResult.to_summary() implementation:**
- Group results by method_name
- Calculate per-method averages: avg precision, recall, F1, processing time
- Return dict: `{method_name: {"precision": X, "recall": Y, "f1": Z, "avg_time": T, "num_videos": N}}`

**Error handling:**
- Catch all exceptions during method.analyze()
- Store exception message and traceback in MethodVideoResult.error
- Continue with other videos/methods (don't fail entire harness)
- In to_table(), display errors as "ERROR" in metrics columns

**Imports needed:**
- `import time` for timing
- `from datetime import datetime` for timestamps
- `from typing import List, Optional, Dict, Tuple`
- Framework: `from src.framework.registry import get_registered_methods`
- Framework: `from src.framework.result import MethodResult`
- Evaluation: `from src.evaluation.evaluator import SegmentEvaluator, EvaluationMetrics`
- Evaluation: `from src.evaluation.ground_truth import GroundTruthLoader, GroundTruth`
- Utils: `from src.utils.video import VideoLoader`

Export from `evaluation/__init__.py`: `TestHarness`, `HarnessResult`, `MethodVideoResult`
