  <action>
Create `src/evaluation/` directory and port Swift SegmentEvaluator to Python.

**Port these classes/functions exactly:**

1. **TimeRange dataclass** (matching Swift struct):
   - `start: float`, `end: float`
   - `duration` property: `end - start`
   - Use `@dataclass` from stdlib

2. **EvaluationMetrics dataclass**:
   - `tp: int`, `fp: int`, `fn: int`
   - `precision: float`, `recall: float`, `f1: float`
   - `fp_rate: float`, `fn_rate: float`
   - Computed properties for precision/recall/f1 from tp/fp/fn

3. **SegmentEvaluator class** with static methods:
   - `iou(detected: TimeRange, ground_truth: TimeRange) -> float`
     * Intersection: `max(0, min(d.end, g.end) - max(d.start, g.start))`
     * Union: `max(d.end, g.end) - min(d.start, g.start)`
     * Return 0.0 if union == 0
   - `evaluate(detected: List[TimeRange], ground_truth: List[TimeRange], iou_threshold: float = 0.5) -> EvaluationMetrics`
     * Greedy matching: each detected matches best ground truth above threshold
     * Each ground truth can only match once
     * Returns tp, fp, fn counts
   - `calculate_rates(detected: List[TimeRange], ground_truth: List[TimeRange], video_duration: float) -> Tuple[float, float]`
     * FP rate: (extra detected duration / video_duration) × 100
     * FN rate: (missed ground truth duration / total ground truth duration) × 100
     * Use greedy overlap calculation matching Swift logic (lines 122-140)

**Type hints:** Use `from typing import List, Tuple` for Python 3.13 compatibility.

**Implementation notes:**
- Match Swift logic line-by-line for evaluate() and calculate_rates()
- Greedy matching in both functions: once a ground truth is matched, skip it
- Handle edge cases: empty lists, union=0, video_duration=0

Export from `__init__.py`: `SegmentEvaluator`, `TimeRange`, `EvaluationMetrics`
  </action>

Create shared video loading utilities for accessing iOS TestResources videos.

**Create these classes:**

1. **VideoMetadata dataclass**:
   - `path: Path`
   - `filename: str`
   - `duration: float` (seconds)
   - `fps: float`
   - `width: int`, `height: int`
   - `frame_count: int`

2. **VideoLoader class**:
   - `VIDEO_DIR` constant: `Path(__file__).parent.parent.parent / "app" / "SportCrunchTests" / "TestResources" / "Videos"`
   - `resolve_path(filename: str) -> Path`:
     * Accepts filename like "tennis-shot-1.mp4"
     * Returns full path: `VIDEO_DIR / filename`
     * Validates file exists, raises FileNotFoundError if not
   - `get_metadata(video_path: str | Path) -> VideoMetadata`:
     * Uses OpenCV `cv2.VideoCapture` to extract metadata
     * Reads: fps (CAP_PROP_FPS), frame_count (CAP_PROP_FRAME_COUNT), width/height
     * Calculates duration: `frame_count / fps`
     * Raises ValueError if video cannot be opened
   - `list_available() -> List[str]`:
     * Returns list of `.mp4` and `.mov` files in VIDEO_DIR
     * Sorts alphabetically

**OpenCV usage:**
- Import `cv2` (already in requirements.txt as opencv-python)
- Use `cv2.VideoCapture(str(path))` for metadata extraction
- Always release video capture: `cap.release()`

**Path handling:**
- Use `pathlib.Path` throughout
- Convert to `str` only when passing to cv2
- Support both `str` and `Path` input types

Export from `__init__.py`: `VideoLoader`, `VideoMetadata`
