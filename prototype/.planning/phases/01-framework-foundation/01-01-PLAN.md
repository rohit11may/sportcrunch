  <name>Task 1: Create result dataclasses and enums</name>
  <files>src/framework/result.py</files>
  <action>
Create `src/framework/result.py` with the following components:

1. `BaseState(StrEnum)` - Minimum required FSM states:
   - `ACTIVE = auto()` (serializes as "active")
   - `INACTIVE = auto()` (serializes as "inactive")

2. `ParamType(StrEnum)` - Supported parameter types:
   - INT, FLOAT, BOOL, STRING, CHOICE

3. `ParamDef` dataclass - Single parameter definition:
   - `name: str`
   - `type: ParamType`
   - `default: Any`
   - `description: str`
   - `min_value: Optional[float] = None`
   - `max_value: Optional[float] = None`
   - `choices: Optional[List[str]] = None`

4. `ConfigSpec` dataclass - Parameter specification for a method:
   - `params: List[ParamDef] = field(default_factory=list)`
   - `to_defaults() -> dict` method returning param names to defaults
   - `validate(config: dict) -> dict` method that validates and fills defaults

5. `MethodResult` dataclass - Result from segmentation:
   - `video_path: str`
   - `video_duration: float`
   - `segments: List[Tuple[float, float]]` - [(start, end), ...]
   - `fsm_timeline: List[Tuple[float, str]]` - [(timestamp, state), ...]
   - `processing_time: float`
   - `method_name: str`
   - `method_version: str`
   - `intermediate_data: dict = field(default_factory=dict)`
   - `__post_init__` validation:
     - FSM timeline cannot be empty
     - Timeline must be sorted by timestamp
     - Timeline must start near 0 (allow 0.1s tolerance)
     - Timeline must cover full video duration (within 0.1s)
     - Required states (active, inactive) must be present

Use patterns from RESEARCH.md. Import from enum (StrEnum, auto), dataclasses (dataclass, field), typing (Any, List, Tuple, Optional).
  </action>

<task type="auto">
  <name>Task 2: Create ABC and registry</name>
  <files>src/framework/method_base.py, src/framework/registry.py</files>
  <action>
Create `src/framework/method_base.py`:

1. `SegmentationMethod(ABC)` - Base class for all methods:
   - `@property @abstractmethod name(self) -> str` - Human-readable name
   - `@property @abstractmethod version(self) -> str` - Version string
   - `@abstractmethod analyze(self, video_path: Path | str) -> MethodResult`
   - `@abstractmethod get_config_spec(self) -> ConfigSpec`
   - `def get_viz_hooks(self) -> Dict[str, Any]` - Default returns empty dict (optional override)

Import ABC, abstractmethod from abc. Import Path from pathlib. Import Dict, Any from typing.
Forward reference MethodResult and ConfigSpec as strings in type hints, or import from result.py.

Create `src/framework/registry.py`:

1. Module-level `_METHOD_REGISTRY: Dict[str, Type[SegmentationMethod]] = {}`

2. `register_method(cls)` decorator:
   - Instantiate cls() to get name (requires no-arg constructor)
   - Check for duplicate registration, raise ValueError if exists
   - Store class (not instance) in registry
   - Return cls unchanged

3. `get_registered_methods() -> Dict[str, Type[SegmentationMethod]]`:
   - Return copy of registry dict

4. `get_method(name: str) -> Type[SegmentationMethod]`:
   - Return class from registry or raise KeyError with available methods

Import Type, Dict from typing.
  </action>
